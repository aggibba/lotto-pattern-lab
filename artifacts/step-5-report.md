## 3. Exact Trend Weighted formula

Within the main pool and special pool separately, normalize each input as
`x(number) / max(1, maximum x across that pool)`.

`samplingWeight = 1 + 4 × (0.30 × recent20 + 0.25 × recent50 + 0.20 × recent100 + 0.20 × appearances + 0.05 × gapLowerBound)`

Values in the expression are normalized inputs. The recent counts come from the
newest min(20/50/100, selected count) drawings within the selected period.
Appearances cover the selected period. Gap uses Step 3's observed lower bound:
zero for the newest appearance, or selected drawing count if never observed.
This does not assume a never-observed number's exact earlier gap.

Weights lie between 1 and 5. Main numbers use sequential weighted sampling without
replacement; the special ball uses its separately normalized pool. All coefficients,
baseline, and strength live in src/config/generator.ts. Future drawings and earlier
rule eras are excluded before statistics are calculated. These are generator
sampling weights, never winning probabilities.

## 4. Exact Pattern Score

Only sorted MAIN numbers enter scoring. Each categorical component is
`100 × observed category count / largest observed category count`.
Unobserved categories score zero. Low boundary is floor((rule minimum + maximum)/2).

| Component | Category / calculation | Weight |
|---|---|---:|
| Odd / Even | Number of odd main balls | 20% |
| Low / High | Number at or below the low boundary | 20% |
| Sum | floor(main sum / 25), i.e. 0–24, 25–49, etc. | 20% |
| Spacing | floor(average adjacent gap / 5) | 15% |
| Consecutive | At least one adjacent gap equals 1: yes/no | 15% |
| Common pairs | 100 × mean historical count of all candidate pairs / largest historical pair count | 10% |

Average adjacent gap = (maximum main − minimum main)/(main count − 1).
All candidate pairs count, including unseen pairs with count zero. Components use
the same selected historical period. Final score is the sum of component score ×
weight/100, rounded to two decimal places. Displayed contributions are individually
rounded, while the total uses full precision. Weights total 100%; invalid weights
are rejected. Empty history prevents generation because a historical score is
unavailable. Same mains, dataset, and period produce the same score, independent
of special ball and RNG. Configuration is in src/config/patternScore.ts.

Every result and saved score displays:
“Pattern Score measures similarity to historical drawing patterns. It does not
represent the probability of winning.”

## 5. Random implementation

Start with every integer in the verified rule's main pool. Pick a uniformly indexed
entry, remove it, and repeat for rule.mainBallCount; sort the result. Independently
pick a uniformly indexed special ball. No historical metric or score enters
sampling. The special ball may equal a main number. Range/count values come from
LotteryRuleSet; generator modules contain no lottery-specific ranges. Math.random
is the default RNG. Injected RNG outputs must be finite and in [0, 1).

## 6. Balanced implementation

Choose one historical drawing uniformly from the selected period, thereby sampling
observed joint structures according to their historical frequency. Generate 200
uniform random main candidates. Keep the first candidate with the lowest distance
to the sampled structure:

`|odd−targetOdd|/k + |low−targetLow|/k + |sum−targetSum|/(R×k) + |meanGap−targetMeanGap|/(R/(k−1)) + I(consecutive differs)`

Here k is the main-ball count and R is main maximum minus minimum. The five
normalized distance terms have equal influence. Candidate count is configurable.
This bounded nearest-structure sampler preserves variety without always forcing
the modal structure. It does not use number frequencies, pairs, or special balls
in candidate selection. Special ball is generated uniformly and separately.

## 7. Duplicate prevention

Canonical key: sorted main integers joined by commas, then `|`, then special ball.
A Set rejects duplicate complete combinations in a batch. Maximum attempts =
requested batch size × 100 (configurable). Exhaustion throws a visible retry-limit
error; no incomplete batch is returned. Card regeneration also checks all other
cards, with a 100-attempt guard. Identical mains with different special balls are
valid distinct complete combinations.

## 15. Remaining limitations / deliberate scope

- Pattern Score is a configurable descriptive heuristic, not calibrated odds.
  Bin choices and component weights affect the number.
- Balanced approximates sampled structures within 200 candidates; it does not
  guarantee exact structure matches or exact historical distribution reproduction.
- Math.random is not cryptographic randomness; seeded RNG injection is available
  for testing. No backtesting engine was implemented.
- Saved combinations belong to this browser/origin and can be lost when local
  storage is cleared. No accounts or sync. Scores remain generation-time snapshots.
  Storage read/write errors are visible; corrupt saved data is not silently overwritten.
- API availability and archive revisions can affect future verification. Tests use
  actual retrieved data and may need rerunning if the source changes between calls.
- The pre-existing data cache has a one-hour TTL; explicit refresh or expiry can
  retrieve new data. Changing period does not fetch history.
- Generation requires at least one selected verified drawing to produce a meaningful
  historical score. Short windows are disclosed using the existing analysis warnings.
